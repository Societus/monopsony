The binaries themselves were removed from git history 2026-09-15; these
checksums pin the exact bytes of the deployed copies so any binary in the
wild can still be verified as ours.

Build provenance: v0.1.0-rc1 tag state (Sprint 5, commit subject
"Sprint 5: Hardening + Auth Foundation → v0.1.0-rc1"). Rebuild with
`RUSTFLAGS="--remap-path-prefix=/home/$USER=/build"` so future artifacts
do not embed build-host paths.
