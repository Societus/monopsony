## Design
Sync decoders (call sites spawn_blocking). Every function returns entries on
success and a structured error on garbage — never panics on hostile input.

### API
```rust
pub struct IndexEntry {
    pub name: String,
    pub version: String,          // raw version string from the index
    pub sha256: Option<String>,   // hex; pacman %SHA256%, apk c:c
}
pub enum ParsedIndex {
    Pacman { entries: Vec<IndexEntry> },
    Apk    { entries: Vec<IndexEntry> },
}

/// Decode + parse. detect by magic bytes, not extension:
/// zstd magic 0x28 B5 2F FD, gzip magic 1F 8B, else raw.
pub fn parse_index(bytes: &[u8]) -> Result<ParsedIndex, IndexError>;

pub struct IndexError(pub String);   // impl Display + std::error::Error
```

### pacman .db / .files format (descriptor directories in a tar)
- Decompress (zstd or gzip or raw) → tar archive.
- Each top-level dir `<pkgname>-<version>/` contains `desc` (plain text,
  `%KEY%\nvalue` blocks; keys: %NAME%, %VERSION%, %SHA256%, %BASE%).
- Yield one IndexEntry per desc: name=%NAME%, version=%VERSION%,
  sha256=%SHA256% (empty → None).
- Tar bombs: cap total decompressed bytes (e.g. 256 MB) and entry count
  (e.g. 100k) — error out beyond. Cap per-desc read at 1 MB.

### APKINDEX (apk-index.tar.gz)
- Decompress gzip → tar → single `APKINDEX` file.
- Entries separated by blank line; fields `key:value` one per line:
  `P:name`, `V:version`, `C:c:<b64-ish hash>` — sha256 when `C:` starts `c:`
  (Q1wr...-style base64; convert: after "c:", it's hex for our purposes ONLY
  if it decodes to 32 bytes — else None; do not guess).

### Dispatch + repo_key
- `pub fn looks_like_index(url_path: &str) -> bool` — path ends `.db` (pacman),
  `APKINDEX` (apk), or `.db.tar.gz`. Used by slice 4 to decide whether to
  buffer-and-parse a response body.
- `pub fn repo_key_from_url(canonical_url: &str) -> String` — scheme://host +
  directory of the path (strip last segment). This IS the repo_key contract
  (context pack).
- `pub fn package_key_for(manager_kind: &str, name: &str) -> String` —
  `format!("{manager}:{name}")` (single place so the format can't drift).
